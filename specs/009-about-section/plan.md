**Branch**: `009-about-section` | **Date**: 2026-05-18 | **Spec**: /specs/009-about-section/spec.md

## Summary
Implement the About section using a terminal-style window atom (`TerminalWindow`) and an organism section (`AboutSection`). The section will feature a multilingual typewriter greeting, bio paragraphs, and info cards, all animated with Framer Motion.

**Target Platform**: Web
**Project Type**: Web application
**Performance Goals**: 60fps animations, CLS < 0.1, Lighthouse ≥ 90.
**Constraints**: Arabic font fallback (EC-001), 1024px grid collapse, respect reduced motion.

## Phase A — Implement TerminalWindow atom
- **Files**: `frontend/components/ui/terminal-window.tsx`
- **Implementation**: Create a Client Component (`'use client'`) that accepts `title`, `children`, `className`, `showDots`, and `animate`. Use Framer Motion for the entry animation. Hardcode dot colors as requested (#ff5f57, #ffbd2e, #28ca41).
- **Gotcha**: Ensure `overflow: hidden` is applied to clip content at rounded corners.
- **Verification**: Render `TerminalWindow` with dummy content and verify traffic lights and shadow.

- **Gotcha**: Ensure no naming collisions.

## Phase D — Implement section heading (FR-004)
- **Files**: `frontend/components/sections/about-section.tsx`

- **Verification**: Greetings cycle: "Hello, World!", "Marhaba!", "Assalam o Alaikum!".

## Phase F — Implement info cards (FR-003)
- **Files**: `frontend/components/sections/about-section.tsx`

## Phase G — Implement scroll animations (FR-005)
- **Files**: `frontend/components/sections/about-section.tsx`, `frontend/components/ui/terminal-window.tsx`

- **Verification**: Content fades/slides up as the user scrolls.
