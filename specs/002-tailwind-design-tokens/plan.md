## Summary

Implement 58 design tokens in `tailwind.config.ts` to establish the "Modern Terminal" visual identity. The tokens cover colors (dark/light palettes), typography (JetBrains Mono/Geist Sans), spacing, borders, shadows, and performance-optimized animations. This system will serve as the foundation for all subsequent portfolio features.

## Sequenced Implementation Plan

### Phase A — Replace shell with full config skeleton
- **Exact change**: Replace current `tailwind.config.ts` with a skeleton containing all `theme.extend` keys (colors, fontFamily, fontSize, spacing, borderRadius, borderWidth, boxShadow, keyframes, animation, screens).
- **Token count**: 0
- **Risk**: Breaking existing build if `content` paths are incorrect.

### Phase B — Implement Token Spec 1: Colors
- **Exact change**: Add 16 tokens (8 dark, 8 light) to `theme.extend.colors`.
- **Token count**: 16
- **Risk**: Contrast ratio violations; verified hex values against Constitution.

### Phase C — Implement Token Specs 2–3: Typography + Font sizes
- **Exact change**: Add `fontFamily` (mono, sans) and `fontSize` (xs-4xl with explicit line-heights).
- **Token count**: 26 (16 colors + 2 fonts + 8 sizes)
- **Risk**: Font fallback chain must prioritize monospace for terminal feel.

### Phase D — Implement Token Specs 4–6: Spacing, Radius, Border
- **Exact change**: Add `spacing` (5), `borderRadius` (4), and `borderWidth` (2).
- **Token count**: 37 (26 + 5 + 4 + 2)
- **Risk**: Mixed units; ensure rem for layout and px for small borders/radii.

### Phase E — Implement Token Specs 7: Box shadows
- **Exact change**: Add `boxShadow` (5) including terminal `glow`.
- **Token count**: 42 (37 + 5)
- **Risk**: Over-glow on light mode; ensure alpha levels are appropriate.

### Phase F — Implement Token Specs 8–9: Animations + Keyframes
- **Exact change**: Add `keyframes` (7) and `animation` (8).
- **Token count**: 57 (42 + 7 + 8)
- **Risk**: Layout thrashing; strictly use `transform` and `opacity`.

### Phase G — Implement Token Spec 10: Breakpoints
- **Exact change**: Add `terminal-sm` to `theme.extend.screens`.
- **Token count**: 58 (57 + 1)
- **Risk**: Collision with default Tailwind screens; use `extend` to append.

### Phase H — Final assembly and verification
- **Exact change**: Run `tsc --noEmit` and verify token count manually.
- **Token count**: 58
- **Risk**: Syntax errors in TypeScript config.
